# 财报抽取复核台

把上市公司年报 PDF 里的**资产负债表、利润表、现金流量表**抽成结构化数据，
带勾稽校验和一个左右对照的复核界面。

```
年报 PDF  ─┬─► 页面/标题定位 ─► 表头解析 ─► 行项目 → 标准科目
           │        │              │            │
           │        └── 跨页接续    ├── 单位识别（元/千元/万元/百万元）
           │                       ├── 上年/本年分列
           │                       └── 合并/母公司分离
           └─► 扫描版走 OCR ─────────┘
                                  ▼
                     结构化数据 + 每个数字的页/坐标
                                  ▼
                     勾稽校验 ─► 复核界面（原文 ↔ 结果）
```

## 快速开始

```bash
pip install -e .                       # 或 pip install -r requirements.txt

python3 -m finreport generate          # 生成 24 份合成年报 + 真值
python3 -m finreport evaluate          # 逐科目算抽取准确率 → data/eval/report.json
python3 -m finreport serve             # 打开 http://127.0.0.1:8765
```

界面上的「导入样例」会把语料库里的文档导入文档库；也可以直接上传任意年报 PDF。

> 依赖：Python 3.11+、PyMuPDF、reportlab、Pillow、pytesseract，
> 以及系统里的 `tesseract`（含 `chi_sim` 语言包）。只有扫描版需要 OCR。

## 能处理什么

| 需求 | 做法 |
|---|---|
| 定位三张报表所在页 | 按标题正则 + 页面文字层判定；`（续）` 页按页面顶部续接、页脚单位重复等特征并入上一张表 |
| 跨页表格接上 | 语句按"标题页到下一张表标题之间"取页；续页重新识别表头，行按科目去重合并，重复行保留数值更全的一条 |
| 表头多行合并 | 表头区域按词框归属到最近的金额列，支持「年末余额/年初余额」两行表头和「2024年度 + 合并/母公司」两层表头 |
| 上年数/本年数分列 | 列标题按「本期/上期/期末/期初」或标题年份与报告年份比较判定 current/prior；不靠列顺序猜 |
| 单位识别 | 从「单位：人民币万元」等位置读取，支持 OCR 把"万元"拆成两行、"人币千民元"这类错字；金额统一换算为**元** |
| 科目名称不一致 | 标准科目表 + 别名 + 归一化（去掉编号、"其中："、"减："、附注引用、括号注释）+ 受控模糊匹配 |
| 合并报表 vs 母公司报表 | 四列表格（合并/母公司 × 两年）按列拆成两张报表；两张两列表按标题的「合并/母公司」区分 |
| 勾稽校验 | 资产=负债+权益、小计=明细之和、营业利润→利润总额→净利润链条、现金流量表内部勾稽、跨表现金勾稽；容差随报表单位缩放 |
| 点击数字定位原文 | 每个金额都记录 PDF 页号与词框坐标，前端按百分比换算成高亮框 |
| 扫描版 OCR | 无文本层（或标题识别失败）时自动走 Tesseract；逐词置信度低于阈值的单元格在界面上高亮 |

## 命令

```bash
# 生成语料（版式/单位/是否扫描都随机，另存真值）
python3 -m finreport generate --out data/corpus --n 24 --scanned-every 4

# 单份 PDF
python3 -m finreport extract data/corpus/pdf/doc_01.pdf --out /tmp/out.json
python3 -m finreport extract some_scan.pdf --ocr

# 批量评测（--doc 可只跑指定文档，--workers 并行）
python3 -m finreport evaluate --corpus data/corpus --out data/eval/report.json
python3 -m finreport evaluate --doc doc_01 --doc doc_04

# 复核台
python3 -m finreport serve --port 8765
```

## 目录

```
src/finreport/
  accounts.py    标准科目表、标签归一化、科目匹配
  values.py      金额解析、单位识别
  pageparse.py   PDF/OCR 词框 → 行候选（列切分、被粘连数字拆分）
  extract.py     标题定位、跨页分组、表头/列/口径解析、行抽取
  validate.py    勾稽规则
  pipeline.py    单文档流程（扫描检测、置信度汇总）
  data.py        合成财务数据（含勾稽关系，可注入错误场景）
  corpus.py      年报版式渲染器（多版式/多单位/可栅格化为扫描件）
  generate.py    语料批量生成
  evaluate.py    与真值逐科目比对
  evalrun.py     批量评测
  server.py      FastAPI 后端
web/             复核界面（原生 JS，无构建步骤）
tests/           单元测试 + 端到端测试
```

## 复核界面

- **文档库**：每份文档的报表张数、单位、页数，以及勾稽错误数、修改数。
- **抽取结果**：左侧报表、右侧原文页。点任一数字即跳页并高亮该数字在原 PDF 上的位置；
  双击或 Alt+点击可直接改数，改完立即重算勾稽。OCR 低置信度单元格有底纹和百分比。
- **勾稽校验**：按规则列出"应有 / 实际 / 差异 / 容差"，参与计算的科目可点击定位。
- **人工复核**：把勾稽错误、低置信度、待确认科目匹配、已修改项汇总成待办清单，
  支持标记复核中/通过、导出 CSV。
- **科目对照**：完整标准科目表（含别名），以及当前文档里"原文项目名 → 标准科目"的对应关系，可手工修正。
- **准确率**：读取评测报告，按报表 / 文档 / 科目展示准确率与错误样例。

## 语料与准确率口径

`generate` 造 24 份年报，随机组合：

- 单位：元 / 千元 / 万元 / 百万元（含 0 位小数）
- 口径：合并、母公司分表，或四列合并表
- 版式：有无表格线、有无附注列、不同字号行距、不同表头措辞、不同科目写法（别名）
- 分页：三张表顺序随机，长表强制跨页
- 干扰项：目录、审计报告、主要会计数据、所有者权益变动表（版式类似资产负债表）
- 扫描件：每 4 份有 1 份栅格化为图片 PDF（可带轻微旋转）
- 错误场景：部分文档故意把资产总计、小计、权益合计或净利润写错，用来验证勾稽校验

每份 PDF 伴生 `truth/<doc_id>.json`，记录每个标准科目在每个口径、每一年的**精确元值**
（按该文档真实单位与小数位取整后换算），以及每张表的页码范围。

评测口径：

- **数值准确率** = 抽取值与真值**完全相等**的（科目 × 口径 × 年份）数 / 总真值数
- **单位识别正确率** = 单位识别正确的报表数 / 报表总数
- **页定位正确率** = 抽取页范围覆盖真值页范围的报表数 / 报表总数

`data/eval/report.json` 里还有按科目汇总的错误样例，界面的「准确率」页直接读取。

## 已知限制

- OCR 对低分辨率扫描件的数字误读无法完全避免；界面依赖置信度高亮 + 勾稽校验兜底，
  最终以人工复核为准。
- 科目匹配覆盖 A 股常规报表项目；金融、保险等特殊行业科目需要扩充 `accounts.py`。
- 勾稽容差按报表申报单位缩放（万元报表容差 ≥ 1 万元），极端舍入差异仍可能报 warning。
- 版式差异极大的募集说明书、H 股英文报表不在当前范围内。
